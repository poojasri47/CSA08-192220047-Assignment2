Q1 – DECISIONS WITH MANY BOUNDARIES
Topic: if statements, if-elif-else, subsidy eligibility, and complexity

A household is eligible for a full subsidy if it consumes 100 units or less. Between 101 and 200 units, it receives a partial subsidy only if it has a ration card. Above 200 units, no subsidy is given unless a household member is above 80 years old.

A. Compare separate if statements with if-elif-else

def subsidy_separate(units, ration, senior):
    if units <= 100:
        print("Full subsidy")

    if 101 <= units <= 200 and ration:
        print("Partial subsidy")

    if units > 200 and senior:
        print("Special subsidy")

    if not (units <= 100 or
            (101 <= units <= 200 and ration) or
            (units > 200 and senior)):
        print("No subsidy")


def subsidy_elif(units, ration, senior):
    if units <= 100:
        result = "Full subsidy"
    elif 101 <= units <= 200:
        if ration:
            result = "Partial subsidy"
        else:
            result = "No subsidy"
    else:
        if senior:
            result = "Special subsidy"
        else:
            result = "No subsidy"

    return result


households = [
    (100, False, False),
    (101, True, False),
    (150, True, False),
    (200, False, False),
    (201, False, False),
    (250, False, True),
    (90, True, False),
    (180, False, True)
]

for units, ration, senior in households:
    print("\nUnits:", units, "Ration card:", ration,
          "Senior above 80:", senior)
    print("Separate if statements:")
    subsidy_separate(units, ration, senior)
    print("if-elif-else:", subsidy_elif(units, ration, senior))


B. Alternative implementation using Boolean conditions

def check_subsidy(units, ration, senior):
    if units <= 100:
        return "Full subsidy"
    elif 101 <= units <= 200 and ration:
        return "Partial subsidy"
    elif units > 200 and senior:
        return "Special subsidy"
    else:
        return "No subsidy"


print(check_subsidy(100, False, False))
print(check_subsidy(150, True, False))
print(check_subsidy(250, False, True))


C. Complexity
Time complexity: O(1) per decision because the number of conditions is fixed.
Space complexity: O(1).

Discussion:
Separate if statements are independent, so more than one block can run if conditions overlap. An if-elif-else chain selects only one branch. For this rule, the if-elif-else design makes the mutually exclusive outcomes clearer.

Q6 – RECURSION AND ITS LIMITS
Topic: staircase problem, recursion, memoisation, call counts, and iteration

A person can climb 1 or 2 steps at a time. Calculate the number of ways to climb n steps.

A. Plain recursion and call counting

calls = 0

def ways_naive(n):
    global calls
    calls += 1

    if n <= 1:
        return 1

    return ways_naive(n - 1) + ways_naive(n - 2)


for n in range(1, 7):
    calls = 0
    print("n =", n, "ways =", ways_naive(n), "calls =", calls)


B. Memoisation

from functools import lru_cache

calls = 0

@lru_cache(maxsize=None)
def ways_memo(n):
    global calls
    calls += 1

    if n <= 1:
        return 1

    return ways_memo(n - 1) + ways_memo(n - 2)


for n in [10, 20, 25, 30]:
    ways_memo.cache_clear()
    calls = 0
    result = ways_memo(n)
    print("n =", n, "ways =", result, "calls =", calls)


C. Check recursion limit for n = 1000

import sys
from functools import lru_cache

@lru_cache(maxsize=None)
def ways(n):
    if n <= 1:
        return 1
    return ways(n - 1) + ways(n - 2)

print("Recursion limit:", sys.getrecursionlimit())

try:
    print("Ways for 1000 steps:", ways(1000))
except RecursionError:
    print("RecursionError: maximum recursion depth exceeded")


D. Iterative solution suitable for n = 1000

def ways_iterative(n):
    if n <= 1:
        return 1

    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b

    return b


for n in range(1, 7):
    print("n =", n, "ways =", ways_iterative(n))

print("Ways for 1000 steps:", ways_iterative(1000))


E. Compare methods

import time
from functools import lru_cache

def naive(n):
    if n <= 1:
        return 1
    return naive(n - 1) + naive(n - 2)

@lru_cache(maxsize=None)
def memo(n):
    if n <= 1:
        return 1
    return memo(n - 1) + memo(n - 2)

def iterative(n):
    if n <= 1:
        return 1
    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

for name, function, n in [
    ("Naive recursion", naive, 30),
    ("Memoisation", memo, 1000),
    ("Iteration", iterative, 1000)
]:
    start = time.perf_counter()
    result = function(n)
    elapsed = time.perf_counter() - start
    print(name, "| n =", n, "| result =", result,
          f"| time = {elapsed:.6f} seconds")


Complexity:
Plain recursion: O(phi^n) time and O(n) call-stack space.
Memoisation: O(n) time and O(n) cache/stack space.
Iteration: O(n) arithmetic operations and O(1) auxiliary space.
The iterative approach is recommended for 1000 steps because it avoids recursion-depth limits and stores only the last two values.

# Python Algorithmic Analysis & Validation (Q1–Q7)

This repository contains the executed code, input files, output screenshots, and the final assignment report for tasks Q1 through Q7. 

## Repository Structure
* **`src/`**: Contains the Python source code for all programs.
* **`data/`**: Contains any required sample inputs.
* **`screenshots/`**: Contains output screenshots for every completed program.
* **`report/`**: Contains the final Markdown assignment report detailing raw counts, timings, and tables.

## Executed Tasks
* **Q1**: Decisions with Many Boundaries (if vs if-elif-else)
* **Q2**: Loops that Count Attempts (while vs for bounds)
* **Q3**: Vehicle Registration Number Validator (String invariants)
* **Q4**: Building Long Text (+= vs join() vs StringIO)
* **Q5**: Functions, Parameters and Scope (Mutable default arguments)
* **Q6**: Recursion and Its Limits (Call counts and memoisation)
* **Q7**: Diagnose, Redesign, and Validate (Iterative optimisation)

## Execution
Run each file directly via Python to view the operation counts and timings:
`python src/q7_diagnose_redesign.py`

Q3 – VEHICLE REGISTRATION NUMBER VALIDATOR
Topic: string operations, slicing, validation, formatting, and complexity

Valid format: 2 letters for state, 2 digits for district, 1 or 2 letters for series, and 4 digits. Examples: TN09AB1234 and KA01M0007.

def normalise(text):
    text = text.strip().upper()
    text = text.replace(" ", "")
    text = text.replace("-", "")
    return text


def is_valid(reg):
    if len(reg) not in (9, 10):
        return False

    if not reg[:2].isalpha():
        return False

    if not reg[2:4].isdigit():
        return False

    series = reg[4:-4]
    if len(series) not in (1, 2) or not series.isalpha():
        return False

    if not reg[-4:].isdigit():
        return False

    return True


def format_number(reg):
    if not is_valid(reg):
        return "Invalid registration number"

    state = reg[:2]
    district = reg[2:4]
    series = reg[4:-4]
    digits = reg[-4:]

    return f"{state} {district} {series} {digits}"


numbers = [
    "tn 09 ab 1234",
    "KA-01-M-0007",
    "TN9AB1234",
    "TN 22 1234 AB",
    "KL 07 CD 4567",
    "MH-12-A-9876"
]

for raw in numbers:
    reg = normalise(raw)
    if is_valid(reg):
        print(raw, "->", format_number(reg), "VALID")
    else:
        print(raw, "->", reg, "INVALID")


Alternative using regular expressions:

import re

def is_valid_regex(reg):
    return bool(
        re.fullmatch(r"[A-Z]{2}[0-9]{2}[A-Z]{1,2}[0-9]{4}", reg)
    )

print(is_valid_regex("TN09AB1234"))
print(is_valid_regex("TN9AB1234"))


Complexity:
Time: O(L), where L is the registration string length.
Space: O(L) because normalisation creates new strings.

Notes:
Python strings are immutable, so methods such as upper() return a new string instead of changing the original. For a normalised string s, s[-4:] returns the last four characters; s[4:-4] returns the series section between the district and final four digits.
